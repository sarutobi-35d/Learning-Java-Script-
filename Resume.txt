RESUMÉ SUR LES NOTIONS

1. VARIABLES :
    const pour une variable qui ne sera jamais reassignée,
    let pour l'inverse,
    var est toujours un moyen de declaration (comme let) mais moins utilisé dans les nouvelles version de JavaScript.

CONCATENATION : le +, les back tic avec ${a} ${b} 
BOOLEAN : le type null et undefined(pour une variable non définie)

LES TABLEAUX : Permettent de save une liste de valeur. 
    * Un tableau peut contenir un autre tableau : const notes = [10, 9, 18, 'hello', [6, 7, 0]]

LES OBJETS : save les données un plus complexe que les tableaux en utilisant des clés
    * une personne : const person = {nom: "Fadil", prenom: "Scarlet"};

NB: En JavaScript, tous les types de variable sont des objets.


2. LES CONDITIONS: 
    permettent de tester quelque chose et de n'executer cette chose que si le test est verifié.
    * If... else
        * ===(les valeurs doivent etre identique(le meme type))
        * une chaine de carectère vide égale à false ('' == false)
        * Les opérateurs logiques ( ET et OU)
        * ! permet d'inversé un booléen (!true égale false)

    NB: Séparé les conditions pour faciliter la lisibilité et la maintenabilité du code.
    
    * switch case permet de verifier une variable à différente valeur.
    *prompt est une instruction d'écriture.
